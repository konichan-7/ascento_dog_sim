# 跨台阶验证（150 mm 台阶）

## 目的与范围

验证四轮足整车驶上 150 mm 高平台的完整行为序列：驱动接近 → 前轮抵住
立面爬升 → 跨坐（前轮在台、后轮在地）→ 后轮爬升 → 四腿同步伸展至台上
标称站姿。**全程车体保持水平（俯仰目标 0）**，前腿在爬升后收缩到最短
长度（轮心与安装座距离最小）。场景文件 `mujoco/quadruped_step.xml` 在
整机模型基础上新增一块 150 mm 平台（顶面 z = 0.15 m，立面前缘 x = 0.9 m，
延伸到 x = 2.5 m），台阶贴面摩擦为示意值 1.5（橡胶面台阶，待实测替换）。
机器人部分与 `quadruped.xml` 完全一致。

## 坐标系与符号约定

与 `AGENTS.md` 及 `docs/leg_kinematics.md` 一致：世界系 +x 为前进方向，
+z 向上；俯仰为正绕机体 +y（左轴），正值低头、负值抬头；高度为机体质心
世界 z（m）；腿角 q 为绝对解析髋角（rad）；力 N、力矩 N·m。

## 水平站姿的关键几何

爬升阶段车体保持水平的关键：**水平低站姿高度 = 台阶顶面 + 轮半径 +
最短腿下探量**。最短腿下探量 d_min = 0.1112 m（q = −15°），因此：

- 水平站姿 h = 0.15 + 0.065 + 0.1112 = **0.3262 m**（平地时即 q = −40°
  标称姿态）；
- 前腿收缩到最短时，前轮恰好位于台面顶部（0.3262 − 0.1112 = 0.215）；
- 跨坐阶段后腿下探 = 0.3262 − 0.065 = 0.261（q ≈ −40°）；
- 台上标称站姿 h = 0.15 + 0.065 + 0.3043 = **0.5193 m**。

## 控制结构

`ascento_dog/control/step_crossing.py` 提供 `StepCrossingController`，
与 MuJoCo 解耦，复用 VMC 的力分配器与解析雅可比。阶段状态机：

| 阶段 | 腿控制 | 说明 |
| --- | --- | --- |
| APPROACH | 全腿力控分配 | 水平低站姿（0.326 m）驶向立面 |
| FRONT_CLIMB | 前腿力控（力帽 70 N）+ 后腿力控 | 前轮沿立面“摩擦齿轮”爬升，前腿随轮爬升自然收缩到最短；前后轮自转+后轮打滑顶压 |
| STRADDLE | 全腿力控 | 前腿在最短长度（轮心近安装座），水平推进至后轮触立面 |
| REAR_CLIMB | 四腿位置伺服：前腿锁最短、后腿按 0.08 m/s 提升调度收缩 | 后轮被拖上立面；前轮打滑顶压、后轮自转 |
| EXTEND | 全腿力控 | 高度斜坡升至台上标称站姿（四腿同步伸展），俯仰归零 |
| DONE | 全腿力控 | 保持 |

### 关键机理与调试结论

- **前爬**：爬升轴（前腿）腿部支撑力被力帽压到 70 N 以下，压轴（后轮）
  在地面打滑产生顶压法向力 N，立面滚动摩擦 μN 超过腿部下压力后把轮子
  “驮”上立面；前腿随轮爬升**自然收缩到最短**（q ≈ −15°），车体由
  俯仰 PD（目标 0）保持水平。此阶段不用位置控制：位置环在入口的保持
  力矩不足会导致车体塌陷。
- **后爬**：四腿位置控制（与几何锁定原理一致）：前腿锁在最短长度
  （关节极限形成刚性支柱，支撑力天然充足，俯仰被几何钉死），后腿按
  提升调度收缩把轮子沿立面拖上去。**后轮拖拽必须用低顶压**（前轮
  目标 0.25 + 0.15 m/s）：顶压经两个前轮放大 1.5 倍后，静摩擦锁死
  力矩会超过伺服拉力上限，导致轮子拖不动。
- 台阶摩擦 1.5 对爬升可靠性的影响：摩擦越大，齿轮辅助越强；但拖拽
  模式下面摩擦同时是阻力，需要低顶压配合。

## 参数来源

连杆尺寸沿用用户给定参数；台阶高度 150 mm、位置、摩擦系数均为场景
示意参数；控制增益沿用 VMC 示意增益（力帽、伺服刚度、顶压偏置等为
调参结果，待实物辨识后替换）。

## 复现与验证

```bash
uv sync --dev
uv run ruff check
uv run ruff format --check
uv run pytest
uv run cross-step --headless --duration 30    # 无界面验证，退出码 0 为成功
uv run cross-step                            # 打开查看器，ESC 退出
```

无界面运行时打印完成用时与终态（四轮心高度、底盘高度、俯仰/横滚）。
`tests/test_cross_step.py` 覆盖：台阶模型编译与几何、安装方向一致性、
完整无界面跨台阶（含终态断言）、参数校验与阶段顺序。

## 已知局限

- 台阶摩擦 1.5 为示意值，未实测；
- 后爬阶段依赖前腿位置锁定与低顶压拖拽，若台阶更高（> 0.2 m 量级）
  或摩擦更低，后轮可能无法建立足够拖拽力；
- 后爬中段车体会有短暂抬头瞬态（约 10°，随轮子爬升恢复），源自后腿
  收缩与轮子爬升的速率差；
- yaw 无闭环，场景为直行。
