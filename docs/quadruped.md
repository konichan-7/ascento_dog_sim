# 四轮足机器人模型

## 模型组成

完整模型位于 `mujoco/quadruped.xml`，包括：

- 一个带自由关节的长方体机身；
- 前左、前右、后左、后右四条 Ascento 闭环腿；
- 四个独立的髋关节执行器；
- 四个独立的车轮转动关节和电机；
- 位于 `z=0` 的 MuJoCo 风格蓝色棋盘地板。

四条腿均使用单腿解析坐标系的 +x 方向作为机体前方。前后腿同向安装，后腿不做镜像或 180° 旋转，因此四条腿具有一致的狗式连杆朝向，并使用完全相同的正逆运动学与装配支路。

## 示意布局参数

用户尚未提供机体 CAD 尺寸和轮距，因此以下参数只用于首版几何验证：

| 参数 | 数值 | 说明 |
| --- | ---: | --- |
| 机体长度 | 0.60 m | 长方体 x 方向全长 |
| 机体宽度 | 0.36 m | 长方体 y 方向全宽 |
| 机体高度 | 0.15 m | 长方体 z 方向全高 |
| 前后髋部位置 | `x=±0.24 m` | 相对机体中心 |
| 左右髋部位置 | `y=±0.20 m` | 相对机体中心 |
| 轮半径 | 0.065 m | 沿用单腿可视化占位值 |

连杆尺寸仍严格使用 `AGENTS.md` 中的用户给定值，没有因整机装配而改变。

## 运动学姿态映射

`set_quadruped_pose` 将同一个局部髋角 `q` 映射到四条腿。查看器播放同步蹲起动作，并根据解析轮心高度调整自由机体的 z 坐标，使四个轮子的最低点始终位于地板 `z=0`。

整车 MJCF 已启用 `-9.81 m/s²` 重力和四个轮子的地面接触，其余连杆仍关闭碰撞；四个髋关节采用 ±40 N·m 的示意力矩执行器，供 VMC 直接写入力矩。仓库不再提供单独的整车运动学播放入口，整车只通过 VMC 闭环脚本运行。

动力学演示使用 `mujoco_vmc.py` 读取底盘高度、姿态、角速度和四个髋角，再调用与 MuJoCo 解耦的 VMC。控制器用模型自动计算的总质量补偿重力，用高度 PID 改变总虚拟推力，并由实时姿态相关的分配矩阵产生 roll/pitch 恢复力矩。

## 启动方法

```bash
uv sync --dev
uv run pytest
uv run vmc
```

在 macOS 上，命令会自动切换到 MuJoCo 的 `mjpython` 启动器。

## 已知局限

- 机体尺寸、安装位置、质量和惯量尚未由 CAD 或实物确认。
- 轮半径、几何密度、接触摩擦、控制增益和执行器力矩限制仍为示意参数。
- 只有车轮参与接触；尚未建立真实轮胎、弹性腿、驱动器带宽、传感器噪声或接触状态估计。
- VMC 已能独立分配四腿竖直力，但轮速和整车水平运动控制尚未实现。

完整 VMC 推导、符号约定和饱和处理见 `vmc.md`。
